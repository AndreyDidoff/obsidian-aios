# Regras de Listagem e Algoritmo de Busca (Artistas)

As regras de busca e ranqueamento de Artistas no aplicativo cliente (ui-client) seguem um cálculo estrito para equilibrar a relevância orgânica e a monetização do ecossistema[cite: 14]. A arquitetura da consulta no banco de dados deve respeitar a seguinte ordem de execução:

## 1. Filtro Base (Obrigatório)
A consulta inicial aplica um filtro absoluto para garantir que apenas os prestadores viáveis sejam retornados[cite: 1, 3, 6]:
*   **Região:** A busca filtra a área, zona ou cidade configurada pela pessoa usuária cliente[cite: 4, 14].
*   **Especialidade:** O Artista precisa ter um *match* exato com todas as especialidades exigidas na busca (múltiplas escolhas no filtro atuam como condicionais SOMADAS)[cite: 1, 3, 4, 6].
*   **Data e Hora:** Validação da disponibilidade na agenda para o momento desejado[cite: 1, 3, 6].

## 2. Sistema de Pontos (Score Oculto)
Os perfis que passaram no filtro base são então ordenados através de um sistema de pontuação (soma)[cite: 4, 14]:
*   **Plano de Listagem:** O Artista recebe automaticamente 10.000 pontos se possuir este plano premium ativo[cite: 1, 3, 4, 6].
*   **Avaliações (Nota):** O ranqueamento orgânico pode gerar até 5.000 pontos com base na média de estrelas (nota final)[cite: 1, 3, 4, 6].
*   **Pontos Avulsos:** Soma de pontos extras adquiridos em pacotes (vendidos de 100 em 100). *Regra de negócio:* Esta compra é restrita a usuários que já são assinantes de um plano[cite: 1, 3, 4, 6].

## 3. Penalidades (Taxa de Cancelamento)
*   **Desconto por Furos:** A taxa de cancelamento do profissional remove um percentual correspondente dos pontos totais conquistados[cite: 1, 3, 4, 6, 14].
*   **Regra Crítica de Proteção:** A penalidade só é ativada no algoritmo para Artistas que possuam um volume mínimo considerado "seguro" de amostras (a partir de 50 a 100 avaliações)[cite: 1, 3, 4, 6]. O objetivo é não punir de forma desproporcional perfis novatos na plataforma[cite: 1, 3, 6].

## 4. Prioridade Máxima (Fura-Fila)
Certos gatilhos ignoram completamente a pontuação padrão e forçam o Artista para o topo absoluto da listagem[cite: 1, 3, 6, 14]:
*   **Acampamento (Seguidores):** Se o cliente pesquisa em uma região e há Artistas que ele já segue na aba "Acampamento", esses profissionais têm precedência máxima, aparecendo no topo absoluto para reduzir a fricção e forçar a retenção[cite: 1, 3, 4, 6].
*   **Plano Imediato:** Artistas pagantes do plano de atendimento imediato aparecem em destaque e são ordenados internamente pelo horário livre mais cedo[cite: 1, 3, 4, 6].
*   **Novos Usuários:** Profissionais recém-cadastrados recebem 3 dias de "Plano Imediato" gratuito, ficando posicionados na listagem logo abaixo dos pagantes reais desse plano para garantir tração inicial (limitado a um cadastro por usuário)[cite: 1, 3, 4, 6].

## 5. Desempate em Cascata
Caso dois ou mais Artistas atinjam exatamente a mesma pontuação, nota e plano, o sistema é obrigado a aplicar uma cascata rigorosa de desempate[cite: 1, 3, 4, 6, 14]:
1.  **Distância Exata:** Quem está geograficamente mais próximo do endereço pesquisado (calculado em metros/quilômetros)[cite: 1, 3, 4, 6].
2.  **Volume de Avaliações:** O profissional com a maior quantidade de avaliações finalizadas passa à frente, premiando a constância e o histórico gerado para a plataforma[cite: 1, 3, 4, 6].
3.  **Rodízio Randômico (Shuffle):** Se a igualdade persistir, o banco de dados deve aplicar uma randomização na sessão para a entrega do resultado, impedindo que IDs mais antigos no banco tenham vantagem de ordenação padrão[cite: 1, 3, 4, 6].
